# KPI Dictionary & Data Quality Contract

## Project Overview

This project translates a retail business requirement into measurable KPIs
and defines a testable data-quality agreement for trustworthy reporting.

## Domain

Commerce / Retail

## Decision Owner

Sales / Operations Manager

## Project Deliverables

### 1. KPI Dictionary
Defines 8 retail KPIs with:
- Formula
- Grain
- Filters
- Owner
- Refresh cadence
- Data-quality rules

### 2. Data Quality Profile
An executable Python/Pandas notebook that checks:
- Completeness
- Uniqueness
- Validity
- Consistency
- Freshness

### 3. Data Quality Contract
Defines:
- Data-quality rules
- Failure thresholds
- Severity
- Escalation actions
- Responsible owners

## Tools Used

- Python
- Pandas
- Excel
- Jupyter Notebook
- GitHub

## Project Objective

To ensure that retail KPI reporting is based on measurable definitions
and trustworthy, validated data.
